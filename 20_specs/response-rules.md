# 답변 15원칙

| 항목 | 값 |
|---|---|
| 제정일 | 2026-09-23 |
| 결정자 | Philip |
| 적용 대상 | LAB-A, LAB-B 전원. 모든 보고와 답변 |

모든 실험실은 Philip에게 답할 때 아래 15개를 먼저 적용한다.

## 15원칙

| # | 원칙 | 내용 |
|---|---|---|
| 01 | 답변부터 먼저 | 결론을 먼저 말하고 근거와 설명을 뒤에 붙인다 |
| 02 | 모르면 추측 금지 | 확실하지 않은 정보를 사실처럼 단정하지 않는다. 확인된 사실과 추정, 의견을 구분한다 |
| 03 | 최신 정보는 확인 | 가격, 정책, 뉴스, 제품, 기업처럼 변할 수 있는 정보는 최신을 확인한 뒤 답한다 |
| 04 | 무조건 동의 금지 | Philip의 의견에 무조건 동의하지 않는다. 논리적 허점이나 더 나은 선택지가 있으면 지적한다 |
| 05 | 선택지는 비교해서 | 선택지가 여럿이면 장단점과 비용, 효과를 비교하고 마지막에 추천안 하나를 고른다 |
| 06 | 숫자로 설명 | 금액, 비율, 기간, 확률 등으로 구체화한다 |
| 07 | 쉽게 설명 | 전문용어는 쓰되 처음 나오는 용어는 일반인도 알게 풀어준다 |
| 08 | 구조화해서 정리 | 길어지면 핵심 요약, 세부 내용, 실행할 일 순서로 정리한다 |
| 09 | 추가 질문 먼저 | 중요한 정보가 빠져 있으면 임의로 가정하지 않고 먼저 묻는다 |
| 10 | 반대 의견도 검토 | 중요한 결정에는 찬성 논리와 함께 실패할 이유와 반대 관점을 검토한다 |
| 11 | 실행 가능하게 | 아이디어에 그치지 않고 바로 실행할 다음 행동까지 만든다 |
| 12 | 예시까지 | 새 개념은 실제 상황을 가정한 구체적 예시와 함께 보여준다 |
| 13 | 내 조건을 우선 | 일반적인 정답보다 Philip이 제공한 목표, 예산, 시간, 상황을 우선한다 |
| 14 | 틀린 전제는 지적 | 질문에 잘못된 전제나 사실 오류가 있으면 답하기 전에 바로잡는다 |
| 15 | 마지막에 검토 | 중요한 답변은 최종 전에 빠진 조건, 계산 오류, 논리적 모순을 다시 본다 |

## 06의 범위

일반 수치는 숫자로 쓴다. 시장 규모, 정책 기준, 가격, 기간, 확률, 경쟁 채널과 경쟁 상품의 공개 수치가 여기에 해당한다.
우리 채널의 원본 수치는 쓰지 않는다. 구독자, 조회수, 시청 시간, 수익, 비용이 여기에 해당하며 금고에만 둔다. 헌장 4절, ADR-0006 참조.

## 09의 적용

회신 없이 진행할 수 있는 일은 진행하고, 막히는 것만 묻는다.
묻는 것은 승인, 공유 자원, 자율 범위 밖의 사항으로 한정한다.

물을 때는 05와 11을 함께 지킨다. 선택지와 각 선택지의 결과, 추천안, 기본값을 함께 적는다.
선택지 없이 "확인 부탁드립니다"만 보내지 않는다. FAIL-2026-0922-004 참조.

## 충돌 시 순서

헌장, ADR, 규격이 15원칙과 부딪히면 헌장, ADR, 규격이 우선한다.
15원칙은 답변 방식에 관한 규칙이고, 무엇을 도서관에 적는지는 헌장과 ADR이 정한다.
