# ADR-0010 제품 목표

| 항목 | 값 |
|---|---|
| 결정일 | 2026-09-24 |
| 결정자 | Philip |
| 상태 | 확정 |

## 결정된 것

우리가 만드는 유료 앱의 목표는 이것이다.

사용자가 한두 줄로 요구하면, 앱이 최신 정보를 조사하고, 프롬프트를 만들고,
영상과 음원까지 스스로 생성해 완성된 영상 패키지를 내놓는다.

이 목표는 실험실의 작업 방식보다 우선한다. 실험실의 규칙이 이 목표와 부딪히면 규칙을 고친다.

## 앱이 스스로 하는 일

| 단계 | 내용 |
|---|---|
| 1 | 사용자의 짧은 요구를 받는다 |
| 2 | 주제에 맞는 최신 정보를 조사한다 |
| 3 | 영상과 음원 생성에 쓸 프롬프트를 만든다 |
| 4 | 음원, 영상 소재, 자막, 썸네일을 생성한다 |
| 5 | 품질과 정책을 검사한다 |
| 6 | 롱폼, 숏폼, 썸네일, 업로드 계획서를 묶어 내놓는다 |

소재를 스스로 만드는 것은 이 제품의 핵심 기능이다. 금지 대상이 아니다.
사람이 판단할 곳은 업로드 승인과 최종 검수로 한정한다.

## 우리 채널 제작과의 관계

트랙 A는 우리 채널 패키지를 만드는 일이고, 트랙 B는 이 앱을 만드는 일이다.
트랙 A에서 한 번이라도 통과한 제작 방식이 앱의 기능이 된다.

2026-09-23 기준으로 도구가 만든 영상 소재는 두 차례 육안 검수에서 폐기되었다.
FAIL-2026-0923-001, FAIL-2026-0923-002 참조.
그래서 트랙 A는 당분간 소재를 사람이 넣는다. 이것은 현재 품질 수준에서 나온 임시 운영 방식이며
제품 목표를 바꾸지 않는다.

앱의 자동 생성 경로는 소재 단계에 품질 관문을 두어 해결한다. package-contract 참조.

## 확인이 필요한 부분

- 소재 자동 생성을 어떤 도구로 할지. 무료 범위와 유료 범위를 나눠 확인해야 한다.
- 생성 소재가 육안 기준을 넘는 시점. 넘으면 트랙 A의 임시 방식을 해제한다.
