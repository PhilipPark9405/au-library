# ADR-0011 실행 경로와 모델 배정

| 항목 | 값 |
|---|---|
| 결정일 | 2026-10-01 |
| 결정자 | Philip |
| 상태 | 확정 |

## 배경

실험실의 실행 담당을 OmniRoute 콤보로 돌릴 수 있게 되었다. FACT-041 참조.
한도를 아끼고 작업을 이어갈 수 있지만, 다른 모델이 우리 금지 규칙을 지키는지는 확인된 바 없다.
이 문서의 메모리 기준은 이 프로젝트의 작업 안전 규칙이다. OmniRoute의 시스템 요구 조건이 아니다.

## 결정

작업 성격으로 경로를 나눈다.

| 작업 | 경로 |
|---|---|
| 그림을 보고 판정하는 일. 소재 검수, 컨택트시트 비교 | 기본 모델 우선 콤보 |
| 규칙이 복잡하고 한 번 틀리면 전체를 다시 해야 하는 설계 | 기본 모델 우선 콤보 |
| 문장을 쓰는 일. 계획서, 설명란 | 기본 모델 우선 콤보 |
| 정해진 명령을 돌리는 일. 렌더 실행과 감시, 측정, 파일 정리 | 대체 모델 우선 콤보 |

## 지켜야 할 것

- 실행 담당은 배차 확인을 작업마다 반복하지 않는다. 작업 자체에 집중한다.
- 배차 검증이 필요한 경우에만 별도로 수행한다. 실제 배차 판정 기준은 OmniRoute Logs다.
- 판정 순서는 Combo, Provider, Model, 같은 요청 흐름의 fallback이다.
- 로그를 확인하지 않았으면 "실제 Provider와 Model은 로그 미확인"이라고 기록한다.
- 실행 담당은 `/model`로 모델을 바꾸지 않는다. 사용자가 명시적으로 지시할 때만 한다.
- 작업 결과와 배차 정보를 섞지 않는다.
- 작업 결과에는 읽은 것, 수정한 것, 생성한 것, 검사 결과, 남은 문제를 기록한다.
- 배차 정보는 실행 담당 자신이 직접 확인할 수 있는 범위까지만 기록한다.
- 메모리가 부족하면 사용 가능 메모리와 주요 프로세스를 보고하고 멈춘다.
- 사용자 승인 없이 브라우저, WSL, 컨테이너, 개발 서버를 종료하지 않는다.
- 실행 담당은 OmniRoute 인프라를 임의 변경하지 않는다.
- Combo 수정, Provider 추가/삭제, API Key 생성/삭제, OAuth 재로그인, 과금 설정 변경은 사용자 또는 PM의 명시적 지시가 있을 때만 한다.
- 아래 금지 사항이 걸린 작업은 기본 모델로 한다.
  다른 실험실 워크스페이스 접근 금지, 비밀 값 출력 금지, 업로드 금지
- API 키와 토큰은 채팅에 적지 않는다. 환경 변수나 프로필 파일에만 둔다.

## 쌓을 것

- 대체 모델 경로로 돌린 작업의 결과를 기록한다. 규칙 위반과 결과 차이를 본다.
- 8시간 렌더가 첫 시험이다. 판단이 거의 없고 시간이 긴 작업이다.

## 폐기 조건

- 대체 모델 경로에서 금지 사항 위반이 한 번이라도 나오면 그 경로를 중단하고 기록을 남긴다.
