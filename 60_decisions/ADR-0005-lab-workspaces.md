# ADR-0005 실험실별 워크스페이스

| 항목 | 값 |
|---|---|
| 결정일 | 2026-09-21 |
| 결정자 | Philip |
| 상태 | 확정 |

## 결정된 것

각 실험실은 아래 지정된 자기 워크스페이스에서만 프로젝트를 진행한다.
워크스페이스는 Philip이 C:\Dev\유튜브 제작\ 아래에 생성했다.

| 실험실 | 워크스페이스 |
|---|---|
| LAB-A | C:\Dev\유튜브 제작\LAB-A-Youtube-Claude-Workspace |
| LAB-B | C:\Dev\유튜브 제작\LAB-B-Youtube-Chatgpt-Workspace |
| LAB-C | C:\Dev\유튜브 제작\LAB-C-Youtube-Gemini-Workspace |
| LAB-D | C:\Dev\유튜브 제작\LAB-D-Youtube-DeepSeek-Workspace |

## 금지

- 다른 실험실의 워크스페이스를 리뷰하지 않는다.
- 다른 실험실의 워크스페이스 폴더를 열거나 읽지 않는다.
- 다른 실험실의 워크스페이스에서 작업하지 않는다. 파일을 만들거나 고치거나 옮기지 않는다.

## 워크스페이스가 아닌 것

| 경로 | 성격 |
|---|---|
| C:\Dev\유튜브 제작\au-library | 공동 도서관 정본. 모든 실험실이 읽는다 |
| C:\Dev 의 과거 유튜브 제작 폴더 | 참고 자료. FACT-020 참조. 정본으로 지정하지 않는다 |
| C:\Dev\유튜브 제작\산출물 | 과거 산출물 보관 폴더 |

과거 폴더와 산출물에서 가져오는 것은 시행착오의 사실이다. 구조를 가져오지 않는다.

## 근거

ADR-0004 는 실험실의 아키텍처, 서브에이전트 구성, 프롬프트, 작업 순서를 공유하지 않도록 정했다.
워크스페이스를 서로 열어보면 구조가 공유되고 네 실험실이 하나가 된다.
실험실 사이에 오가는 것은 도서관의 사실 기록과 실패 기록뿐이다.
