# ADR-0009 LAB-D 중단

| 항목 | 값 |
|---|---|
| 결정일 | 2026-09-24 |
| 결정자 | Philip |
| 상태 | 확정 |

## 결정된 것

LAB-D 의 프로젝트 참여를 2026-09-24 부로 중단한다. 실험실은 LAB-A, LAB-B 두 개다.

## 근거

Philip 이 밝힌 사유다.

- 진행 절차와 속도가 느리다.
- 산출물 품질이 기준에 못 미친다.
- 렌더에 시간이 과도하게 들어간다.
- 안내가 자세하지 않아 Philip 이 매 단계를 직접 처리해야 했다.

도서관 기록으로는 FAIL-2026-0922-001 부터 004, FAIL-2026-0923-001 이 해당한다.
LAB-D 는 로컬 실행 수단이 없어 모든 실행을 Philip 에게 넘겼다. ADR-0007 의 랩 쪽 연결 항목과 관련이 있다.

## 처리

| 대상 | 처리 |
|---|---|
| LAB-D 워크스페이스 | 작업 중단, 동결. 다른 실험실의 접근 금지는 유지한다 |
| LAB-D 기록 | FACT-029, FACT-030, FACT-031, FACT-032 와 실패 기록 5건은 보존한다 |
| 검증된 자산 | 3시간 마스터 음원은 남긴다. 다시 만들면 약 40분이 든다 |
| Control Plane | 등록 대상 실험실은 LAB-A, LAB-B 다 |
| 공유 자원 | LAB-D 의 자원 신청은 무효로 한다 |

## 다른 문서를 읽는 방법

이 결정 이전 문서의 "세 실험실", "3개 실험실" 표기는 두 실험실로 읽는다.
ADR-0005, ADR-0006, ADR-0007 표의 LAB-D 행은 효력이 없다. 폴더는 동결 상태로 남는다.

## 남은 실험실에 적용할 것

- 영상 소재는 사람이 넣는다. 도구가 소재를 지어내지 않는다. package-contract 참조.
- 소스 이미지는 렌더 전에 2200x1238 로 줄인다. FACT-032 참조.
- 품질 게이트는 수치와 육안을 함께 본다. FAIL-2026-0923-002 참조.
