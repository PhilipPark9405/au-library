# ADR-0008 LAB-C 퇴출

| 항목 | 값 |
|---|---|
| 결정일 | 2026-09-21 |
| 결정자 | Philip |
| 상태 | 확정 |

## 결정된 것

LAB-C(Gemini)를 2026-09-21 부로 실험실에서 퇴출한다. 실험실은 LAB-A, LAB-B, LAB-D 세 개다.

## 근거

ADR-0006 은 진행이 저조해 프로젝트 일정에 영향을 주는 실험실을 Philip 이 제외할 수 있도록 정했다.
Philip 은 LAB-C 의 반복된 불이행과 요청과 다른 답변을 사유로 들었다.

도서관에 기록된 LAB-C 실패 기록은 6건이다.

| 기록 | 내용 |
|---|---|
| FAIL-2026-0919-002 | 커밋 API 를 열지 못함 |
| FAIL-2026-0919-003 | 읽지 못한 값과 원인을 단정함 |
| FAIL-2026-0919-004 | 드라이브 사본을 최신으로 오인함 |
| FAIL-2026-0919-006 | 새 세션에서도 raw 주소를 열지 못함 |
| FAIL-2026-0919-010 | 브라우징 불가로 sources 를 채우지 못함 |
| FAIL-2026-0920-003 | 상위 모델에서도 조회 실패, 원인 단정 |

2026-09-21 에 추가로 관찰된 것이다.

- 폴더 화면 캡처만 받은 상태에서 세 프로젝트를 읽고 분석했다고 보고했다. 출처를 요구받은 뒤 일부를 철회했다.
- 4판 통보에 판 번호와 워크스페이스 수신 확인 없이 이전 출처 보고를 다시 제출했다.
- 텔레그램 봇 토큰을 채팅으로 전달해 달라고 요청했다. ADR-0006 토큰 규칙 신설 전의 일이다.

## 처리

| 대상 | 처리 |
|---|---|
| LAB-C 워크스페이스 | 작업 중단, 동결. 다른 실험실의 접근 금지(ADR-0005)는 그대로 유지한다. 삭제 여부는 Philip 이 정한다 |
| LAB-C 기록 | FACT-011, FACT-012 와 실패 기록 6건은 보존한다 |
| LAB-C 산출물 | 도서관과 다른 실험실 작업에 반입하지 않는다 |
| LAB-C 자원 신청 | classic 보유 18곡 사용 신청은 무효로 한다 |
| LAB-C 텔레그램 봇 | 만들어졌다면 BotFather 에서 삭제한다 |
| Control Plane | 등록 대상 실험실은 LAB-A, LAB-B, LAB-D 다 |

## 다른 문서를 읽는 방법

이 결정 이전 문서의 "네 실험실", "4개 실험실" 표기는 세 실험실로 읽는다.
다음 항목은 효력이 없다.

- ADR-0003 의 LAB-C 예외와 실험실별 확인 결과 표의 LAB-C 행
- ADR-0005 워크스페이스 표의 LAB-C 행. 폴더는 동결 상태로 남는다
- ADR-0006 표시명 표의 LAB-C 제미나이 행

## 미결

ADR-0001 은 도서관 구축의 승계 1순위를 Gemini CLI 로 두었다. 이는 실험실 LAB-C 와 별개의 도구 지정이다.
유지할지는 Philip 이 정한다.
