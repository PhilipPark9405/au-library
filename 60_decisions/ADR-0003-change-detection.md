# ADR-0003 도서관 변경 감지 방식

| 항목 | 값 |
|---|---|
| 결정일 | 2026-09-19 |
| 결정자 | Philip |
| 개정일 | 2026-09-21 |
| 상태 | 개정 |

## 결정된 것

판본 확인의 기준은 최신 커밋이다. 커밋 메시지와 커밋 시각으로 판본을 특정한다.
INDEX.md의 판 번호는 보조 표기다.

1차. GitHub 커밋 API 또는 git log로 최신 커밋의 메시지와 시각을 확인한다.

```
https://api.github.com/repos/PhilipPark9405/au-library/commits?per_page=1
```

2차. 커밋 API와 git log를 모두 쓰지 못하는 실험실은 INDEX.md의 최종 갱신 표기로 확인한다.
같은 날 두 번 이상 고치면 날짜 뒤에 판 번호를 붙인다.

Philip의 갱신 통보에는 최신 커밋 메시지를 적는다. 실험실은 자기가 확인한 최신 커밋과 대조한다.

raw 주소와 blob 주소는 판본 확인에 쓰지 않는다. 두 주소가 같은 시각에 함께 이전 판을 반환한 사례가 있다. FAIL-2026-0921-001, FACT-010 참조.

## LAB-C 예외

LAB-C는 어떤 경로로도 도서관을 직접 읽지 못한다. 새 프로젝트와 새 세션에서도 같은 결과였다.
Philip이 세션 시작 시 도서관 내용을 직접 붙여넣는다.
LAB-C는 붙여넣은 내용만 기준으로 삼으며, 다른 경로에서 도서관을 찾지 않는다.

## 근거

raw 주소는 커밋 직후 이전 내용을 반환할 수 있다. FAIL-2026-0919-001 참조.
커밋 API는 같은 시점에 최신 값을 반환했다.
2026-09-21 raw 주소와 blob 주소가 함께 이전 판을 반환했다. FAIL-2026-0921-001 참조. 같은 시각 clone은 최신 판을 반환했다.
INDEX.md의 갱신 표기만으로는 사람이 판 번호 올리는 것을 잊으면 감지가 실패한다.

## 재검토 조건

- LAB-C가 커밋 API를 열게 되면 판 번호 관리를 중단한다.
- 네 실험실 모두 커밋 API를 읽는 것이 확인되면 1차 방법만 남긴다.

## 커밋 메시지 작성

커밋 메시지가 실험실이 읽는 변경 내역이 된다. 무엇이 바뀌었는지 한국어로 짧게 적는다.
