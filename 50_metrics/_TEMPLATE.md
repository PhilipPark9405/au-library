# 주간 성과 양식

파일명: `2026-W38.json`

주 1회만 제출한다. 일일 제출은 하지 않는다.

```json
{
  "week": "2026-W38",
  "entries": [
    {
      "lab": "LAB-A",
      "channel": "econ",
      "uploads": 0,
      "views_24h_avg": 0,
      "ctr_pct": 0,
      "avg_view_duration_sec": 0,
      "shorts_to_longform_pct": 0,
      "package_minutes_avg": 0,
      "suno_downloads_used": 0,
      "transcript_credits_used": 0,
      "human_edits": 0
    }
  ]
}
```

## 필드 설명

- `package_minutes_avg` — 패키지 1건을 만드는 데 걸린 평균 시간.
- `human_edits` — Philip이 직접 손본 횟수. 이 값이 오르면 에이전트 품질이 내려간 것이다.
- `suno_downloads_used`, `transcript_credits_used` — 한도 관리용. 누적이 아니라 그 주에 쓴 양.

숫자만 쓴다. 해석과 평가는 쓰지 않는다.
