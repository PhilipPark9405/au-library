# FACT-026 2026-09-16 classic 검수 지적의 반영 현황

| 항목 | 값 |
|---|---|
| 상태 | 검수 기록과 코드 대조로 확인 |
| 확인일 | 2026-09-21 |
| 제출 | LAB-A |
| 영향 채널 | classic |

## 사실

2026-09-16 검수에서 다섯 가지 개선을 명시했다. v1.6.1 패치에는 한 가지만 반영되었다.

| 지적 항목 | 반영 | 근거 |
|---|---|---|
| 콜라주 크롭 금지, 16:9 독립 원본 | 반영 | v1.6.1 코드에 콜라주 없음. VM01~VM08 전부 1920x1080 |
| 장면 450초 방치 금지 | 미반영 | segment_seconds=450 그대로 |
| 실제 움직임 추가 | 미반영 | zoompan 확대만. 빗방울, 촛불 등 실제 움직임 없음 |
| 곡 정보와 감성 문구 삽입 | 미반영 | drawtext 등 텍스트 레이어 없음 |
| 숏폼 별도 9:16 제작 | 미반영 | crop=608:1080 중앙 크롭 그대로 |

미반영 상태로 2026-09-17에 롱폼과 숏폼이 재렌더되었다.

## 검수에서 확인된 원 문제

- 숏폼 두 편이 사실상 정지 화면이었다. 비트레이트 178kbps 와 171kbps.
- 롱폼에 곡 제목과 감성 문구가 없었다. 기획서에는 훅 문구가 있었다.
- 최종 검수를 실제 파일로 하지 않은 채 업로드 단계까지 넘어갔다.

## 확인이 필요한 부분

- 왜 한 가지만 반영되었는지. unknown.
