# FACT-011 LAB-C의 URL 조회 불가

| 항목 | 값 |
|---|---|
| 상태 | 4회 시도로 확인 |
| 확인일 | 2026-09-19 |
| 제출 | LAB-A |
| 영향 | LAB-C |

## 사실

LAB-C는 아래 조건에서 모두 도서관 주소를 열지 못했다.

| 시도 | 조건 | 결과 |
|---|---|---|
| 1 | 기존 세션, 커밋 API 주소 | 실패 |
| 2 | 새 세션, raw 주소 | 실패 |
| 3 | 새 프로젝트, raw 주소 | 실패 |
| 4 | 상위 모델, raw 주소 | 실패 |

같은 시각 다른 실험실은 같은 주소를 정상 조회했다.

## 운영 방침

LAB-C는 Philip이 세션 시작 시 도서관 내용을 직접 붙여넣는다.
LAB-C는 붙여넣은 내용만 기준으로 삼고 다른 경로로 도서관을 찾지 않는다.

## 확인이 필요한 부분

- 원인. 4회 시도 모두 unknown이다.
- main 형태 주소로도 같은 결과인지는 시험하지 않았다.
