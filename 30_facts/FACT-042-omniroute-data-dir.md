## 사실

- OmniRoute 는 데이터 폴더(DATA_DIR) 안의 storage.sqlite 에 제공자 연결과 콤보 구성을 담는다.
- 같은 버전, 같은 포트로 띄워도 데이터 폴더가 다르면 다른 storage.sqlite 를 쓴다.
  그러면 제공자 연결과 콤보가 통째로 달라진다.
- 기본 데이터 폴더(사용자 폴더 아래 .omniroute)에는 제공자 연결 5개, 콤보 2개만 있었다.
  운영용 데이터 폴더의 storage.sqlite 에는 콤보 5개, 제공자 연결 13개가 그대로 있었다.
- 운영용 데이터 폴더를 지정해 다시 띄우자 콤보와 제공자 연결이 복구됐고,
  실행 담당이 정상으로 시작해 짧은 시험 요청이 성공했으며 로그에서 실제 처리도 확인됐다.

## 상태 점검이 뜻하는 것

- 상태 점검(health)이 정상이라는 것은 서버가 살아 있다는 뜻이다.
  올바른 운영 데이터베이스를 쓰고 있다는 뜻이 아니다.
- 운영 환경을 식별하려면 아래를 함께 봐야 한다.
  버전, 데이터 폴더, 포트, 제공자 연결 상태, 콤보 존재
