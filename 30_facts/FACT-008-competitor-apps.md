# FACT-008 경쟁 앱 두 종의 제품 구조

| 항목 | 값 |
|---|---|
| 상태 | 화면과 판매사 답변 기준. 실사용 미검증 |
| 확인일 | 2026-09-20 |
| 제출 | LAB-A |
| 영향 | 트랙 B |

## 사실

와디즈에 유튜브 영상 자동 생성 앱 두 종이 오픈 예정으로 등록되어 있다.

### AVPF 스튜디오
- 오픈 예정 2026-10-06
- Windows PC 데스크톱 앱
- 2분 다큐 숏츠를 주제 입력 후 8클릭으로 생성
- 대본은 15초 챕터 단위, 챕터당 공백 포함 110~120자
- 이미지 24장을 병렬 생성, 소요 2분 20초
- 영상 생성에 Grok Imagine 1.5 사용
- 알림 신청 302명

### SeriesCast
- 오픈 예정 2026-09-23
- 주제팩 5종으로 채널 5개 운영
- 쇼핑쇼츠, AI사전, 미스터리, 썰캐스트, 플레이리스트
- 수익 경로 3종: 파트너스, 쇼츠 광고, 롱폼 광고
- 제휴 영상에 유료 광고 포함 표시를 자동 삽입
- 마스터 2,890,000원, 정가 29,800,000원
- 알림 신청 238명

## 비용 구조

SeriesCast는 앱 안에서 사용자가 직접 발급한 OpenAI 등의 API 키를 쓴다.
앱 안에 발급 링크와 가이드가 있다.
AI 호출 비용은 구매자가 부담한다. 판매자의 변동비는 발생하지 않는다.

출처: 판매사 AutoCast 문의 답변, 2026-09-19

## 판매 단위

1팩, 3팩, 5팩 중에서 고른다. 3팩은 5종 중 원하는 세 개를 선택한다.
기능 차등은 없고 쓸 수 있는 팩 수와 사용 기간만 다르다.

## 주제팩 5종의 공통점

다섯 종 모두 시의성이 없는 소재를 다룬다.
최신 뉴스를 다루는 팩은 확인되지 않았다.

## 사용자 후기에서 확인된 것

테스터 6명의 체험 후기를 확인했다.

- 6명 중 4명이 생성 버튼을 누르기 전 단계, 즉 기획에서 대본, 장면 분할,
  이미지 구도까지의 준비 과정이 가장 오래 걸리며 제품이 그 구간을 줄여준다고 적었다.
- 6명 중 3명이 최종 결과물은 직접 손봐야 한다고 적었다.
  세 명 모두 이를 불만이 아니라 전제로 서술했다.
- 한 명이 작업 속도가 체감 3배 이상 빨라졌다고 적었다. 측정 방식은 밝히지 않았다.

## 입력 화면 구성

프로젝트명, 영상 목적, 핵심 주제, 타깃 시청자, 게시 플랫폼, 화면 비율,
길이 프리셋(1/3/5/10/15/20분), 내레이션 유무, 자막 범위, 참고 영상.
길이 프리셋에 따라 파트 수가 안내된다. 10분은 파트 6~8개, 20분은 파트 8~12개.

## 확인이 필요한 부분

- 실제 산출물 품질. 소개 화면과 후기 기준으로만 판단했다.
- 두 제품의 실제 판매 결과
- 두 제품의 소개 화면에서 수치 출처 표기 항목은 확인되지 않았다.
  실사용 검증은 하지 않았다.
