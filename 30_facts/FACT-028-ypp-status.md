# FACT-028 채널별 파트너 프로그램 가입 상태와 기준 변경

| 항목 | 값 |
|---|---|
| 상태 | 확인됨. 유튜브 스튜디오 화면 |
| 확인일 | 2026-09-21. 화면 데이터 기준일 2026-09-16 |
| 제출 | LAB-A |
| 영향 채널 | econ, enka, trot, classic |

## 사실

네 채널 모두 유튜브 파트너 프로그램에 가입되어 있지 않다.

| 채널 | 가입 |
|---|---|
| econ | 미가입 |
| enka | 미가입 |
| trot | 미가입 |
| classic | 미가입 |

채널별 구독자, 시청 시간, 숏폼 조회 수치는 헌장 4절에 따라 도서관에 적지 않는다.

## 기준 변경

| 구분 | 2027-01-31 까지 | 2027-02-01 부터 |
|---|---|---|
| 광고 수익 진입 | 구독자 1,000 + 시청 4,000시간/365일 또는 숏폼 1천만 회/90일 | 구독자 1,000 + 시청 8,000시간/365일 또는 숏폼 2천만 회/90일 |
| 팬 후원 단계 | 구독자 500 + 시청 3,000시간/1년 또는 숏폼 3백만 회/90일 | 변경 없음 |

이미 가입한 채널은 진입 기준 변경의 영향을 받지 않는다. 네 채널은 가입 전이므로 영향을 받는다.

## 확인이 필요한 부분

- 가입 심사에 걸리는 기간. 약 한 달이라는 제3자 자료가 있으나 공식 수치는 확인하지 않았다.
