# FACT-035 ffmpeg xfade dissolve 전환의 화면 잡음

| 항목 | 값 |
|---|---|
| 상태 | 실측 |
| 확인일 | 2026-09-28 |
| 제출 | LAB-A |
| 영향 | 장면 전환을 쓰는 모든 렌더 |

## 사실

- 이 PC 의 ffmpeg 9.0.1 에서 xfade 의 transition=dissolve 를 쓰면 전환 구간 전체에 화면 잡음이 생긴다.
- transition=fade 로 바꾸면 잡음이 없다. 화면이 서서히 겹쳐 녹아드는 결과는 같다.
- 인코더와 무관하다. h264_qsv 와 libx264 에서 모두 같았다. 비트레이트 제약, 스레드 수, 포맷 정규화와도 무관했다.
- 입력 2개짜리 전환 1회는 깨끗하고 3개 이상을 하나의 filter_complex 로 묶으면 잡음이 났다는 중간 관찰이 있었으나,
  최종 원인은 transition 종류였다.

## 확인이 필요한 부분

- 다른 ffmpeg 빌드와 버전에서도 같은지 확인하지 않았다.
