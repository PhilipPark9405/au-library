# FACT-017 제작 품질 기준선

| 항목 | 값 |
|---|---|
| 상태 | ffprobe 실측 |
| 확인일 | 2026-09-21 |
| 제출 | LAB-A |
| 영향 | 전 채널 |

## 사실

2026-09-12 ふるさとの駅 패키지다. Genspark Gen Team으로 약 15분 만에 제작되어
EnkaKing 채널에 실제 업로드되었다. 업로드 3일 경과 시점 롱폼 297회, 숏폼 1,200회다.

| 항목 | 롱폼 | 숏폼 |
|---|---|---|
| 해상도 | 1920x1080 | 1080x1920 |
| 프레임 | 30fps | 30fps |
| 영상 코덱 | H.264 | H.264 |
| 영상 비트레이트 | 2,789 kbps | 2,734 kbps |
| 오디오 | AAC 196 kbps | AAC 196 kbps |
| 길이 | 160.31초 | 45.5초 |
| 파일 크기 | 57.21MB | 15.94MB |

## 기준선으로 삼는 이유

실제 채널에 올라가 성과 숫자가 나온 유일한 패키지다.
이 수치를 제작 품질의 하한으로 본다. 미달이면 통과시키지 않는다.

크레딧 비용 부담으로 Genspark를 계속 쓰기 어렵다는 것이 본 프로젝트의 출발점이다.
과제는 이 수준을 외부 크레딧 없이 내는 것이다.

## 확인이 필요한 부분

- 롱폼 길이가 160.31초, 2분 40초다. 채널에 업로드된 영상과 같은 파일인지 확인하지 않았다.
- Genspark 크레딧 소모량. 확인하지 않았다.
