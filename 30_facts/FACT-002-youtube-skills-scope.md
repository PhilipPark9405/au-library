## 사실

TranscriptAPI를 호출하는 Agent Skills 패키지다. 스킬은 12개이고 실질적으로 5개가 핵심이다.

| 스킬 | 기능 |
|---|---|
| youtube-full | 아래 전부 통합 |
| transcript | 타임스탬프 포함 자막 추출 |
| youtube-search | 영상과 채널 검색, 최대 50건 |
| youtube-channels | 채널 업로드 목록 조회, 핸들 해석 |
| youtube-playlist | 재생목록 전체 추출 |

## 할 수 없는 것

영상 생성, 대본 생성, 음원 생성, 썸네일 생성, 업로드. 전부 불가능하다.
읽기 전용 입력 도구다.
