# FACT-034 영상 소재 인공물 검사 방법

| 항목 | 값 |
|---|---|
| 상태 | 실측 |
| 확인일 | 2026-09-30 |
| 제출 | LAB-A |
| 영향 | 모든 채널 |

## 사실

- 해상도와 파일 크기만으로 소재 품질을 판정하면 걸러지지 않는다.
  하늘이나 안개처럼 압축이 잘 되는 정상 사진이 크기 미달로 탈락했고, 잡음 이미지가 통과했다.
- 클립의 0초, 중간, 끝 세 프레임만 보는 검사로는 부족하다.
  안개가 잠깐 걷히며 마을과 조림지가 드러나는 사례 3편, 불타는 손글씨 메모가 나오는 사례 2편이
  세 프레임 검사를 통과한 뒤 컨택트시트에서 발견되었다.
- 2초에서 5초 간격 검사에서 위 사례가 모두 잡혔다.

## 2단계 검사

1단계 자동 판정. 클립마다 3초 간격 프레임에서 아래를 계산해 순위를 낸다.

| 지표 | 잡아내는 것 |
|---|---|
| 소벨 직선 성분 | 도로, 전선, 건물 모서리 |
| 국소 대비 극값 | 어두운 배경의 마을 불빛 |
| 격자 규칙성 | 조림지, 농경지 |
| 8x8 국소 구조 표준편차 | 잡음 이미지. 실제 장면은 칸 사이 차이가 크다 |

2단계 사람 검사. 자동 판정 상위 40편과 하위 무작위 10편을 직접 본다.

## 관찰

- 자동 판정은 흐릿한 도심과 작은 구조물을 놓쳤다. 2단계 사람 검사가 필요하다.
- 8x8 국소 구조 표준편차 관측값은 Pexels 사진 10.0에서 67.7, 기준선 썸네일 35.2였다. 경계값 5.0을 썼다.
