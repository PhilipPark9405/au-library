# FACT-033 Pexels API 한도와 소재 수집 실적

| 항목 | 값 |
|---|---|
| 상태 | 실측 |
| 확인일 | 2026-09-30 |
| 제출 | LAB-A |
| 영향 | 모든 채널의 영상 소재 조달 |

## 사실

- Pexels API 키는 무료다. 기본 한도는 시간당 200회, 월 20,000회다.
- 검색 1회에 최대 80편까지 결과를 받는다. 파일 내려받기는 검색 횟수에 포함되지 않는다.
- 사진과 영상 모두 검색과 내려받기가 된다. 원본 해상도를 고를 수 있다.
- 이용 조건으로 출처 표시를 권장한다. 상업적 사용이 허용된다.

## 수집 실적

| 회차 | 검색 | 받은 편수 | 내용 |
|---|---|---|---|
| 1 | 12회 | 영상 6, 사진 6 | 첫 시도 |
| 2 | 5회 | 50 | 4K 항공 소재 |
| 3 | 14회 | 275 | 대량 수집 |
| 4 | 2회 | 40 | 보충 |

62분 영상에서 장면을 겹치지 않게 채우려면 20~30초 장면 기준 약 150편이 필요하다.

## 제외율

317편을 검사해 최종 215편을 승인했다. 제외율은 약 32퍼센트다.

| 사유 | 편수 |
|---|---|
| 인공물 | 21 + 16 + 1 |
| 품질 미달 | 15 + 12 |
| 카테고리 통째 제외 후 개별 검수로 복원 | 변동 |
