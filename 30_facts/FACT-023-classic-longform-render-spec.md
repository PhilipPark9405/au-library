# FACT-023 classic v1.6.1 롱폼 렌더 사양

| 항목 | 값 |
|---|---|
| 상태 | 원문 코드로 확인 |
| 확인일 | 2026-09-21 |
| 제출 | LAB-A |
| 영향 채널 | classic |

## 사실

render_environment_v161.py 기준이다.

### 영상 처리

1920x1080 원본 이미지를 2200x1238로 확대하고 crop 한 뒤 zoompan 을 걸어 1920x1080 24fps로 출력한다.
확대 배율은 약 1.15배다.

zoompan 프리셋 4종을 세그먼트마다 번갈아 쓴다.

| 프리셋 | 동작 |
|---|---|
| 1 | 중앙 확대, 1.055배까지 |
| 2 | 좌측 고정 확대, 1.05배까지 |
| 3 | 우측 고정 확대, 1.05배까지 |
| 4 | 축소 |

450초 동안 1.055배까지 가는 속도이므로 화면상 거의 정지로 보인다.

### 구성

| 항목 | 값 |
|---|---|
| 세그먼트 길이 | 450초 |
| 세그먼트 수 | 24 |
| 전체 | 10,800초 |
| 이미지 | 8장을 3바퀴 |

### 인코딩

libx264, preset veryfast, CRF 21, 24fps, 오디오 AAC 320kbps.

### 재시작 구조

이미 만들어진 세그먼트가 1MB를 넘으면 건너뛴다. 중간에 끊겨도 이어서 돌릴 수 있다.
3시간 오디오 마스터가 없으면 렌더를 시작하지 않고 종료한다.

## 콜라주 관련

v1.6.1 코드에 콜라주 분할과 크롭은 존재하지 않는다.
2026-09-16 검수에서 지적된 1672x941 8분할 콜라주는 v1.6 의 것이며 v1.6.1 에서 제거되었다.

## 확인이 필요한 부분

- v1.6 코드는 확인하지 않았다.
- drawtext 등 텍스트 레이어가 없다. 곡 정보와 감성 문구가 화면에 나오지 않는다.
