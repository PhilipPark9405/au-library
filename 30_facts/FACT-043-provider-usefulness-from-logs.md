# FACT-043 콤보 등록과 실제 쓸모는 다르다

| 항목 | 값 |
|---|---|
| 상태 | 실측 |
| 확인일 | 2026-10-03 |
| 제출 | Philip, LAB-A 정리 |
| 영향 | 실행 담당을 쓰는 모든 랩 |

## 사실

콤보에 제공자가 등록돼 있다는 것, 제공자가 연결돼 있다는 것, 상태 점검이 정상이라는 것만으로
그 제공자가 실제 운영에서 쓸모 있다고 판단하지 않는다.

2026-10-03 실제 실행에서 관찰된 흐름이다.

| 순서 | 제공자 | 결과 |
|---|---|---|
| 1 | Codex | 정상 처리하다 사용 불가 상태가 됨 |
| 2 | Gemini 계열 | HTTP 429 로 처리하지 못함 |
| 3 | Kilo Gateway 계열 | HTTP 200 으로 작업을 이어감 |

## 기록하는 방식

이 사건에서 "어떤 제공자는 쓸모없다" 라고 적지 않는다.
"그 시점의 그 요청에서 어느 target 이 어떤 상태 코드로 처리했는지" 를 적는다.

제공자의 운영 가치는 최근 실제 로그로 판단한다. 볼 것은 아래다.

- 내장 도구 동작 여부
- HTTP 성공률
- 할당량과 요청 제한 발생률
- 실제 작업에 필요한 문맥을 받아들이는지
- 파일과 셸 작업 성공 여부
- 응답 시간
- 실제 비용

제공자 순서 변경과 제외는 Philip 의 명시적 승인 없이 하지 않는다.
