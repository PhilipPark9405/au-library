# FACT-040 유통사 Content ID 와 본인 채널 소유권 주장

| 항목 | 값 |
|---|---|
| 상태 | 스튜디오 화면 확인과 공식 문서 |
| 확인일 | 2026-09-29 |
| 제출 | LAB-A |
| 영향 | 음원을 유통사로 배포한 채널 |

## 사실

- 유통사를 통해 음원을 Content ID 에 등록하면 본인이 올린 영상에도 소유권 주장이 걸린다.
- DistroKid 의 Content ID 주장은 Interstreet Recordings 이름으로 표시된다. DistroKid 의 Content ID 엔진이다.
- 주장이 걸려도 동영상 도달범위와 채널에는 영향이 없다. 저작권 위반 경고가 아니다.
  수익 창출만 제한된다. 파트너 프로그램 가입 전이면 실제 손해가 없다.
- 해제는 유통사의 허용 목록으로 한다. DistroKid 는 distrokid.com/youtubeAllowlist 다.
- 허용 목록은 영상 단위다. 채널 전체는 등록할 수 없다. 주장이 걸린 뒤에만 등록할 수 있다.

## 확인이 필요한 부분

- 허용 목록 등록 후 주장이 풀리는 데 걸리는 기간.
