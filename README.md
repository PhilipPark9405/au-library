# au-library

4개 독립 실험실이 함께 쓰는 도서관입니다. 실험실은 합치지 않습니다. 이 저장소만 같이 씁니다.

## 이 저장소의 성격

여기에는 **참고할 사실만** 들어 있습니다. 의견, 권고, 지시는 들어오지 않습니다.
무엇을 할지는 각 실험실이 자기 워크스페이스에서 스스로 정합니다.

## 들어오는 것

- 헌장과 금지 사항
- 채널의 확정된 사실 (대상 시청자, 포맷, 금지어)
- 산출물 규격 (JSON 스키마, 파일명 규칙)
- 외부 도구의 검증된 제약 (쿼터, 정책, 한도)
- 실패 기록
- 주간 성과 숫자

## 들어오지 않는 것

- 시스템 프롬프트, 프롬프트 전문
- 파이프라인 구성, 워크플로우 설계
- 원본 대화 로그
- API 키, 계정 비밀번호
- "이렇게 하는 게 좋다"는 판단과 권고
- 대용량 파일 (mp4, wav, png)

이 저장소가 공개인 이유가 여기 있습니다. 공개해도 잃을 것이 없는 것만 넣기로 정했기 때문입니다.
그 대신 다섯 개 런타임 전부가 인증 없이 읽습니다.

## 읽는 방법

세션을 시작할 때 아래 두 개를 먼저 읽습니다.

1. `INDEX.md` — 지금 무엇이 있는지
2. `40_failures/` 중 자기 채널에 해당하는 최근 기록

나머지는 필요할 때 INDEX를 보고 골라 읽습니다.

CLI 환경(Claude Code, Gemini CLI, Codex)은 로컬에 clone 해서 씁니다.
웹 환경(ChatGPT, Genspark)은 raw URL을 직접 가져옵니다.

```
https://raw.githubusercontent.com/<계정>/au-library/main/INDEX.md
```

## 쓰는 방법

각 실험실은 커밋 권한이 없습니다. 표준 양식에 맞춰 파일을 만들어 제출하면 Philip이 올립니다.
양식에 없는 필드를 추가하거나 의견을 덧붙인 제출물은 반려됩니다.
